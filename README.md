# Question-14-Final-Exam
Question 14 Github Repository for Final Exam MGT 665
I chose to work with the obesity levels dataset on Kaggle for this question. For the sake of time, I worked with only five variables SMOKE(smoker) weight, gender, age, and height. Weight was predicted based on the other four features. This kept the model simple for time sake, but may have been too simple to achieve reliable results. The Mean Square Error came out to be 498.655 taking the RMSE we get 22.33. While the dataset does not give a unit of measure, we know this is likely to be in kilograms based on the numbers provided and doing a little research into the dataset owner, AbdElRahman16, we see they are from Cairo so likely this is metric. This would mean we are off by about 22.33 kilograms or nearly 50lbs. This leads us to believe that more variables need to be included to improve upon the accuracy of this regression model.
